# Team Filters and Default Avatar QA

Interactive Team category filtering and the State Council editorial placeholder were checked in a 1280px desktop browser and a 375px mobile browser.

| Check | Result |
| --- | --- |
| Filter categories | Passed. All People, Core, Advisory, Trainers and State Council controls show the expected member counts. |
| State Council avatar | Passed. All 17 State Council cards use the same pale paper/Neem editorial avatar, initials and a clearly visible “Source portrait unavailable” note. |
| Source transparency | Passed. The placeholder treatment is visually consistent without suggesting it is a real member photograph. |
| Desktop layout | Passed. Filters remain compact above the gallery; State Council cards retain a readable multi-column composition. |
| Mobile layout | Passed. Filter controls wrap without overflow, and State Council default-avatar cards stack with legible names and labels. |

The browser interaction script also confirmed that each filter returns its expected number of records and the All People control restores the 37-person roster.
